## 本地运行

需要兼容项目依赖的 Node.js 与 npm。在 `23andMe/presentation` 内执行：

```sh
npm ci
npm run dev
```

构建：`npm run build`。语音合成说明见 [TTS providers](23andMe/presentation/scripts/tts-providers/README.md)，密钥通过本地环境变量提供。
